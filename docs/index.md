# Welcome on Odin

Odin was previously created and managed by the Caelus company, a 4 persons startup from Lille in the North of France.

We always deeply wanted to be part of the **sovereign** perspective. So what better way to do that than giving you all ours code behind an opensource license.
We are still maintaining the code, and contributing in order to give you some new features in the future.

However, right now the code is yours. 💚
